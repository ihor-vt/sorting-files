### 📂 Recursive File Sorter

This simple project recursively sorts files in a given folder 📁 using a terminal-based UI built with **Bubble Tea** 🍵.

#### 🚀 Features:

- Interactive CLI interface for sorting selection 🖥️
- Recursively organizes files based on predefined rules 📑
- Cleans up empty folders after sorting 🗑️
- Provides analytics on sorting results 📊

#### ⚡ Usage:

```sh
go run main.go /path/to/folder
```

or run the program and enter the folder path manually.

#### 🛠️ Dependencies:

- [Bubble Tea](https://github.com/charmbracelet/bubbletea) for the interactive UI

Happy sorting! 🎉
